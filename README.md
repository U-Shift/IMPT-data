# IMPT Data

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.19887968.svg)](https://doi.org/10.5281/zenodo.19887968)

This repository aims to document the data treatment and processing steps for the IMPT (Index for Monitoring Transport Poverty) calculation.

A detailed methodological report is available at [u-shift.github.io/IMPT-data](https://u-shift.github.io/IMPT-data/).
